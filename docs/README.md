This `docs/` folder is the source for this repo's GitHub Pages site —
`https://second-hand-tigers.github.io/<your-github-username>-career-learnings/`
— not subject-matter documentation. For the actual content, see the repo's
main [README](../) and [Wiki](../../wiki).

## Files here

- `_config.yml` — site title, description, theme (Slate — the standard
  theme across every site in this network).
- `index.md` — home page. Mirrors the main README; keep the two in sync
  when you edit either one.
- `about.md` — About Me page, served at `/about/`.

## Note on links

Relative links inside `index.md`/`about.md` resolve differently once
served from the Pages site than they do on GitHub. Links to the Wiki, the
repo root, or `/slides` should be full `https://github.com/...` URLs, not
relative paths.
