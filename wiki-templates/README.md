GitHub's **Use this template** button only copies this repo's file tree —
it does **not** copy the Wiki, Issues, or Project board. The file in this
folder is a starting point you paste into your own Wiki by hand once
you've enabled it (Settings → Features → Wikis).

Steps:

1. Enable the Wiki on your new repo.
2. Create the **Home** page and paste in `Home.md` from this folder,
   replacing the placeholders.
3. Delete this `wiki-templates/` folder from your own repo — it's
   scaffolding for setup, not part of your final repo.

See [SETUP-GUIDE.md](../SETUP-GUIDE.md) at the repo root for the full
setup checklist.
